API-Referenz
============

Die öffentliche API ist die für Aufrufer vorgesehene, bewusst kleine
Paketoberfläche. Die Entwicklerreferenz dokumentiert darüber hinaus die
Bausteine, aus denen diese Oberfläche zusammengesetzt wird.

Das :download:`Architekturdiagramm der Pipeline (PDF) <../abbildungen/architekturdiagramm.pdf>`
zeigt, wie die hier dokumentierten Komponenten im Verarbeitungsablauf
zusammenspielen.
